# Native Next Cycle workspace

Mode: Operate. Ordinary extension of the pinned PA Next production static UI.
The existing Wistron blue/green, light/dark tokens, Rack 3D and material assets
are authoritative. No design-preview proposal is promoted into production.

## Direction contract

THESIS: Select canonical nodes, review one durable PRE and watch the same run
through completion or interruption, without confusing completion with health.

OWN-WORLD: Use Next's sidebar, system font, blue links, green primary buttons,
native form fields and desktop tables. Cycle CSS stays scoped.

STORY: Pick chassis/nodes; inspect blockers and impact; create PRE; confirm its
version; monitor counts; inspect persistent operational events and raw evidence.

FIRST VIEWPORT: Native hash-route workspace with page title and history/create
actions, SYNTHETIC label, then form and chassis-grouped node selection. Run view
starts with lifecycle, health, coverage and worker freshness. Console expands
inside this route. The node matrix and evidence remain reachable by page scroll.

FORM: Desktop application workspace at 1366×768 and 1920×1080. Selection survives
filtering; route reload/back reconnect to the durable run. One bounded console.
No mobile acceptance is claimed, no new raster assets are commissioned.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

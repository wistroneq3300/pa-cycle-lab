# Cycle Test surface

This is a scoped extension of the copied PA Manager interface, not a redesign.
The approved handoff specifies the entry, target selection, PRE confirmation,
progress, graceful stop and report flow. Mode: Operate.

## Direction contract

THESIS: Project-scoped cycle operation with visible fixed targets and explicit PRE
approval. Keep configuration, execution completion and hardware health distinct.

OWN-WORLD: Inherit PA's system typography, white/light gray panels, navy text,
teal actions, compact native tables and existing dark theme tokens. No new imagery.

STORY: Select machines, inspect preparation behavior, create PRE, approve the
specific findings and targets, monitor each node, stop after round, inspect evidence.

FIRST VIEWPORT: Project name and SYNTHETIC mode, runner status; target table and
conditions on left, persisted project jobs on right. Once a job is selected its
PRE/progress appears first. On phones the layout stacks and tables scroll locally.

FORM: Direct extension of the approved PA project modal; no concept seed is required
for a specified local extension. Controls inherit the existing PA interface.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

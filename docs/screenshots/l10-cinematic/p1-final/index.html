L10 Cinematic P1 修復與驗收

基準：b3664ea97d52f1e6d756de00cfb5a8c84821c0cc
分支：codex/cinematic-l10-assembly-intro。本次只修正正式入口管路版本、水流辨識度、SSD 共面衝突及相關載入保護。

驗收環境為本機真實 Chromium / NVIDIA RTX 4070 / ANGLE D3D11 WebGL，非軟體繪圖。Backend 使用既有 preview fixtures 隔離；沒有接觸硬體或部署正式服務。影片為原生 recordVideo（25 fps 編碼）；render-loop telemetry 約 60 fps，兩者不能混稱。

水流動態驗收

保留 flow 10.5–14.3 秒（含淡入）、39.7 秒全片；沒有延長到 5–6 秒，也沒有移動 Rack 時序。固定相機的三個時間點：GPU travel 依序為 0.595 → 1.530 → 2.465，幾何／相機簽章不變，波包位置與渲染像素改變。供水 → 冷板 → 回水方向與分支接縫相位保持一致。

逐路 uniform／矩陣／像素差異證據。全片連續播放中，11.0–14.3 秒的完整水流期間每幀維持 22 個 fluid draws，travel 持續更新，原生解析度 1，沒有 JS／WebGL error。查看原尺寸影片能辨認波包沿蛇形彎道及支管移動；保留原始細管徑，因此縮小成 dashboard 縮圖時方向感較弱。

影片完整錄製 Replay，期間沒有 seek；上方固定相機圖片是另外的確定性檢查，不冒充電影相機。原始水流材質並未被任意不透明替代 Mesh 遮擋；full-profile 渲染維持既有展示剖視與 22 條流體，不修改冷板或管殼幾何。

SSD 連續驗收

既有 setOrbit 控制的 8 秒連續相機掃描，18 個 SSD-01 寬面追蹤點；這是揭露共面衝突的診斷相機，非 authored film camera。Before 重現 660 次深色外殼／鎳色面切換；After 沒有深色覆蓋樣本或材質切換。相鄰採樣亮度跳動 P95 由 64.0092 降為 1.2126（降低 98.11%），全程 native resolution=1；沒有改動 PBR、光照或 Depth 狀態。

CPU 幾何測試覆蓋全部八顆 SSD、procedural 與實際 coolingV2 build：32 組重疊變為 0、無裂縫／邊框自重疊；其餘 I/O triangles 及非 I/O meshes byte-identical。

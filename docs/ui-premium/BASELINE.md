## Routes and presentation owners

| Area | Route / entry | Primary owner | Baseline contract |
|---|---|---|---|
| Overview | default shell / dashboard | `validation-overview.*`, `cinematic.*` | Hero V3 frozen |
| Systems / projects | `#/projects` | `product.*`, `workspace-ux.*` | L10/L11, search, project and system actions preserved |
| System detail / nodes | machine workspace | `product-detail.*`, `operations-ux.*` | exact active node and binding preserved |
| Test Case selection | `openAssignTask(name)` | `app.js`, `engineering-ux.*`, `workspace-ux.*` | same library API, selection Set and clipboard payload |
| PA Agent | `PA_Agent.open(...)` | `pa-agent.js`, scoped rules in `style.css` | same run/message/attachment API and OK/GO gate |
| Cycle | `#/cycle*` | `cycle-workspace.*`, `cycle-console.*` | PRE/confirm/run/stop/recovery/evidence semantics preserved |
| Telemetry | machine Telemetry tab | `telemetry-native.*`, `telemetry-provision.*` | READY/stale/error and source semantics preserved |
| Inspection | machine Health tab | `system-inspection.js`, `inspection-refinement.css` | rules, AI advice and raw evidence remain separate |
| Terminal / Broadcast / KVM | existing action entries | existing terminal/KVM modules | target, transport and framebuffer behavior frozen |
| Rack + CDU | Rack workspace | rack/equipment scene owners | regression only; no redesign |

`app/static/index.html` loads the selection override chain as `app.js` → `product-detail.js` → `engineering-ux.js` → `workspace-ux.js`. Changes therefore stay in the existing owner or the established integration wrapper. No new renderer wrapper, MutationObserver or global override file was added.

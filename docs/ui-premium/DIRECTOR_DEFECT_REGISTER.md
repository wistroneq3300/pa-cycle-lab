Test labels in the repository used an earlier D-number sequence, so this register maps by defect content, not by the label printed by a test.

## Integrity notes

- No defect is closed merely because there is no body overflow or page error.
- Fixture screenshots are labelled synthetic/fake-provider and do not establish hardware health, successful exporter installation, SSH/RFB routing, or Cycle device execution.
- The targeted contrast matrix closes the measured solid-background regressions, but the partial audit still omits image/canvas/SVG/video, disabled content, opacity/filter/blend cases and approximates complex backgrounds. It is not full WCAG certification.
